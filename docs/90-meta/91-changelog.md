# Changelog
Major documentation milestones, website changes, and Covenant revisions.

---

## v0.2.0 — Overhaul, Preamble, Title Renumbering
- Removed L6 Land eigibility and rotations.
- Removed tag-dropping rules.
- Overhaul in the presentation of information. 
- Renumbered all Covenant Titles/anchors for clarity (Council is Title 2, Clerks Title 3, etc.) and implemented unique tX-artY-secZ anchors.
- Improved dark-mode alert/callout contrast for Catppuccin styling so notes/info/cautions stay legible.

---

## v0.1.2 — Framework Simplification
- Removed land eligibility/rotation promises; protection now tied to lands currently held by members.  
- Deferred tag-related handling to a future amendment and stripped automatic blacklist references.  
- Updated voting, guides, FAQs, and land governance pages to reflect the leaner framework.

---

## v0.1.1 — Harboring Clarification & Discord Guide
- Added explicit 4-hour grace window after official notice for harboring; removed offline-proof requirement.  
- New Discord Server Guide with role/permission maps, channel tree, thread policy, and admin setup steps.  
- Set explicit slugs across docs to eliminate broken links.

---

## v0.1.0 — Init
- Imported NAP 9 Covenant, Guides, Philosophy, and Quickrefs into Docusaurus structure.  
- Authored Covenant sections (membership through amendments) with evidence/vote/land protection rules.  
- Added role guides (Clerk, Council, Delegate, New Alliance) and philosophy/design theory.  
- Established meta pages (changelog, credits) for future releases.

---

### How to Propose Changes
- Submit amendment proposals via `#nap-proposals` following the Amendment requirements.  
- For docs-only tweaks (typos, clarity), open an issue/PR and note if rules are unaffected.  
- CI/CD runs on push; preview site updates automatically after merges.
