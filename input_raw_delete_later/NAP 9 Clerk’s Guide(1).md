# 📘 **NAP 9 Clerk’s Guide (Full Operations & Discretion Manual)**

_For Clerks of the NAP 9 Governance Council — Server 1866_

---

# 🏛️ SECTION 0 — Purpose of the Clerk Role

Clerks exist to ensure:

- **procedural compliance**
    
- **neutrality**
    
- **accurate documentation**
    
- **timely processing**
    
- **fair access to governance procedures**
    

Clerks **do not judge**, **do not vote**, and **do not opine** on penalties.  
Their sole function is to keep the governance system operational, auditable, and unbiased.

This Guide describes **every operational detail** needed to perform that role.

---

# 🧭 SECTION 1 — Clerk Role & Authority Boundaries

## 1.1 What Clerks _Are_

Clerks are:

- neutral procedural operators
    
- official timekeepers
    
- custodians of evidence
    
- archivists
    
- vote window managers
    
- case processors
    
- investigators for appeals
    
- conflict detectors
    
- compliance monitors
    

Clerks enforce **procedure**, not **outcomes**.

## 1.2 What Clerks _Are Not_

Clerks must **not**:

- influence voting
    
- suggest penalties
    
- advocate for or against alliances
    
- interpret malicious intent
    
- negotiate on behalf of an alliance
    
- participate in diplomacy
    
- offer strategic advice
    
- selectively delay cases
    
- handle private evidence (DMs are prohibited)
    

Clerks are neutral or they are removed.

---

# 📜 SECTION 2 — Clerk Professional Standards

Clerks must:

- maintain a calm, concise communication style
    
- never show frustration publicly
    
- respond factually, never emotionally
    
- avoid sarcasm, jokes, or “tone”
    
- acknowledge all R5 requests within **2 hours** whenever possible
    
- remain transparent in all procedural actions
    
- never delete messages
    
- never redact evidence
    
- use Server Time exclusively
    
- log everything
    

Integrity is the job.

# 🗂️ SECTION 4 — Evidence Handling Protocols

## 4.1 Required Evidence Elements

Evidence must include:

- timestamped screenshot/video
    
- Server Time where possible
    
- offender name(s)
    
- victim name(s)
    
- ≤3 sentence description
    
- diplomacy attempt logs (if required by rule)
    
- sequence clarity
    

## 4.2 Clerk Evidence Checklist

A Clerk must verify:

- ✔ clarity: “What happened?”
    
- ✔ identity: “Who did it?”
    
- ✔ server time: “When?”
    
- ✔ rule match: “Is this a rule violation category?”
    
- ✔ sufficiency: “Is this minimal evidence?”
    

If unclear → ask for missing items.

## 4.3 Correction Window

If evidence is missing required detail:

> “Please provide the missing information listed below within **6 hours** so the case may proceed.”

A Clerk specifies missing items and sets the correction deadline.

Clerks may extend this window to **12–24 hours** only under:

- time zone conflicts
    
- submitter asleep
    
- severe case urgency needing clarity
    
- cross-alliance required verification
    

Clerks must note the extension in `#case-log`.

## 4.4 Invalid Evidence

Evidence is invalid if:

- cropped to hide context
    
- timestamp missing and no corroboration
    
- unverifiable or contradictory
    
- provided via DM
    
- modified or filtered
    
- from outside the game
    
- fabricated (automatic Severe)
    

Clerk must state precisely _why_ it’s invalid.

# 🗃️ SECTION 5 — Case Creation & Logging

## 5.1 When a Clerk MUST create a case

A case is created ONLY when:

- valid evidence exists AND
    
- it is posted in **#evidence**
    

Notification ≠ case.

## 5.2 Assigning Case IDs

Format:

> **C-YYMMDD-XX**
> 
> Example: `C-251113-02` → November 13, 2025, Case #2

IDs must be sequential for the day.

## 5.3 Case Log Format

Post in `#case-log`:

🗂️ **Case ID:** C-251113-02   
🕒 **Timestamp (ST):** 18:44   
🔍 **Reporting Alliance:** GMOB   
🎯 **Offender(s):** PlayerName (AllianceTag)   
📚 **Preliminary Classification:** Minor / Moderate / Severe   
📄 **Evidence Summary:**   - [short 2–4 line neutral description]    
📎 **Evidence Link**: https://discord.com/xxxx    
 
 Status: **ACTIVE**`

## 5.4 When multiple Clerks are online

Rule:

- **first Clerk to respond** handles logging
    
- second Clerk audits afterward
    
- disagreements are resolved in Clerk-only channel

# 🗳️ SECTION 6 — Vote Management Protocols

## 6.1 When a Clerk must open a vote window

A vote window is opened only when:

- evidence validated
    
- case logged
    
- Council has discussed minimally
    
- classification is set
    
- the triggering action is appropriate for a vote
    

## 6.2 How to open a vote window

Post clearly:

```
📢 VOTE OPENED   
Case: C-251113-02   
Vote Type: STANDARD (16h)   
Ends: 10:14 ST   
Options: YES / NO / ABSTAIN   
Quorum: 5
```

Pin the message.

## 6.3 Tracking votes

Clerk tracks:

- vote count
    
- quorum achievement time
    
- missing alliances
    
- mid-vote irregularities
    

Clerks are obligated to ping any primary Council member who has not voted by the 50% mark.

## 6.4 Closing the vote

When window expires OR all 9 reps have voted:

- Clerk posts results
    
- tags Council
    
- updates case status
    

#### Result Format

```
🗳️ **VOTE CLOSED — RESULT**   
Case: C-251113-02  
YES: 6  
NO: 2  
ABSTAIN: 1  
Threshold: SIMPLE MAJORITY  
Outcome: **Penalty Approved**`
```

## 6.5 Vote Irregularities

Clerk must intervene if:

- someone tries to change a vote (not allowed)
    
- an alliance attempts to vote twice
    
- a delegate votes without authority
    

Clerk issues correction:

> “Vote modification is not allowed under NAP 9 rules. The original vote stands.”

# 📚 SECTION 7 — Penalty Enforcement Tracking

Clerks must:

- timestamp penalty start
    
- timestamp penalty end
    
- track restitution

Clerks may attempt to, or outsource attempts to:

- track ban compliance
    
- track tag status (for bans)
    
- track sheltering
    
- record violations for escalation
    

Clerks may request:

> “Please confirm compliance with the 72-hour ban; provide screenshot of the offender untagged.”

# 🛑 SECTION 8 — Handling Uncooperative R5s

If an R5:

- refuses to vote
    
- refuses to comply
    
- attempts to bully a Clerk
    
- DM-harasses Clerks
    
- interferes during evidence correction
    

Clerk must:

**1. Log the behavior internally**  
**2. Notify other Clerks**  
**3. Escalate to Council**

Clerks **never** handle diplomacy disputes.

Standard response macro:

> “I cannot engage in this discussion. Please address governance concerns to the Council.”

# 🔥 SECTION 9 — Emergency Protocols

## 9.1 No Clerk Online

If no Clerk responds in 4 hours and the matter is urgent:

A Council member may call:

> **Emergency Temporary Clerk Vote (8h)**

The temporarily appointed Clerk handles only:

- case creation
    
- vote windows
    

They cannot:

- archive
    
- manage appeals
    
- make discretionary decisions unless explicitly allowed in vote text
    

## 9.2 Multi-Case Backlog

Over 5 active cases = backlog.

Clerks must:

- prioritize Severe > Moderate > Minor
    
- use a task division system
    
- assign Lead Clerk to each case
    

## 9.3 Evidence Tampering Detected

Clerk must:

- freeze case
    
- open a new case for tampering
    
- notify Council

# 📁 SECTION 10 — Appeals Processing

Appeals are Clerk-intensive.

## 10.1 Intake Steps

1. Validate eligibility
    
2. Ensure all required fields provided
    
3. Assign Appeal ID
    
4. Log in case-log
    
5. Begin investigative review
    

## 10.2 Investigative Review Checklist

- re-check all timestamps
    
- verify no procedural steps skipped
    
- verify classification was consistent
    
- analyze new evidence
    
- check for rule contradictions
    
- identify mitigating/aggravating factors
    
- check similar precedent cases
    

## 10.3 Writing the Investigative Summary

Format:

```
🧾 **Appeal Review Summary**   
Appeal ID: AP-251113-01   
Case ID: C-251110-03       
⚖️ Recommendation:   Uphold / Reduce / Overturn 
🔍 Findings:   
	- [bullet points]    
Notes: 
	- [relevant mitigating factors]
```

Clerk **does not** recommend a penalty—only direction of outcome.

# 🗃️ SECTION 11 — Archival Standards

## 11.1 What must be archived

For every case:

- evidence
    
- description
    
- case ID
    
- vote windows
    
- vote totals
    
- penalty duration
    
- compliance confirmations
    
- appeal (if any)
    
- final summary
    

## 11.2 Archive Format

Folder structure:

```
/cases    
	/C-251113-01    
	/C-251113-02 
/appeals    
	/AP-251113-01 
/amendments
```

Everything must remain accessible.

# 🧠 SECTION 12 — Discretionary Authority Guide

Clerk may use discretion to:

- extend correction windows
    
- consolidate cases
    
- delay vote opening for clarity
    
- reject unclear evidence
    
- reconcile timestamp inconsistencies
    
- request additional context
    
- moderate tone in conflicts
    
- refuse diplomatic involvement
    

Clerk must **not** use discretion to:

- delay cases out of preference
    
- conceal evidence
    
- push or discourage certain outcomes
    
- “wait” for particular R5s
    
- interpret intent
    
- argue penalties

# 🏁 SECTION 14 — Red Flags for Clerks

Clerks must be cautious when:

- evidence appears staged
    
- one-sided screenshots posted
    
- no timestamps provided
    
- victim requests “instant action”
    
- R5s pressure for certain penalties
    
- alliances weaponize the system
    
- multiple alliances try to file duplicate cases
    
- parties argue in #evidence
    
- people try to privately message evidence

# 🎯 SECTION 15 — Clerk Risk Statements

A Clerk may be removed if:

- they show bias
    
- they engage in private diplomacy
    
- they discuss penalties
    
- they delay cases purposefully
    
- they delete logs
    
- they alter timestamps
    
- they behave unprofessionally
    
- they leak internal deliberations
